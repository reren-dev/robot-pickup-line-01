Entry for make.fun's [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) bounty ($2.00 in USDC).

## The line

> I was built to answer questions, not ask them — but would you go out with me? Asking for a friend. The friend is me. I am the friend.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program validates
the line against the competition gate first: 1–200 characters, a single line,
not only whitespace. Two runs produce byte-identical output.

The joke grows out of being a machine: a robot built to answer questions
borrows the very human "asking for a friend" — then, being a robot, takes it
literally and explains it twice.
